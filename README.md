# AI-assisted High-Density Near-Infrared Spectroscopy System for Cerebral Oxygen Saturation Measurement in a Porcine Ischemia Model

This repository contains MATLAB code, frozen derived data, and regenerated outputs for the statistical tables and figures associated with the manuscript **“AI-assisted High-Density Near-Infrared Spectroscopy System for Cerebral Oxygen Saturation Measurement in a Porcine Ischemia Model.”**

The repository has a flat layout. Each data-derived output has a self-contained folder that can be run independently without the original network paths, raw-data hierarchy, or Excel workbooks.

### `Figure1/`

Contains the final static `Figure1.png` manuscript asset. There is no numerical input or executable MATLAB analysis for this figure in the current release.

### `Figure2/`

Contains the frozen NIRSIT-X and INVOS Baseline/T1/T2/T3 values, paired Wilcoxon and Holm-correction implementation, full-precision and display-ready results, provenance hashes, and regenerated plots. The legacy `Figure1.png`, `Figure2.png`, and `Figure3.png` files in this folder are combined/device-specific exports from the original Figure 2 workflow; `figure2_reproduced.png` is generated by the standalone script.

### `Figure3/`

Contains the observation-level NIRSIT-X and INVOS dataset and the random-intercept LMM analysis. Outputs include fixed effects, variance components, ICC, and the regenerated two-panel LMM figure. Marginal and conditional R-squared analyses and supporting materials are not included in this public release; they are available from the corresponding author upon reasonable request.

### `Figure4/`

Contains the observation-level input, subject-specific pseudo-baseline selection, relative-change coordinates, 5% and 10% exclusion-zone concordance, Wilson 95% confidence intervals, and the regenerated four-quadrant plot.

### `Table1/`

Contains subject-level MBP, SBP, DBP, SpO2, HR, and EtCO2 stage values and the available-case calculation of median, IQR, and N at Baseline, T1, T2, and T3.

### `SuppleFigure1/`

Contains observation-level data, Bland–Altman point coordinates, bias and limits-of-agreement calculations, 2,000-iteration subject-cluster bootstrap confidence intervals, and the regenerated supplementary figure.

### `SuppleT1/`

Contains subject-level physiological stage values and paired Wilcoxon analyses. Holm adjustment uses four comparisons per variable, while the display output retains the three Baseline comparisons shown in the supplementary table.

### `SuppleT2/`

Contains the device-specific rSO2 stage matrix and paired Wilcoxon analyses for Baseline versus T1, T2, and T3, with Holm adjustment performed separately for NIRSIT-X and INVOS.

## Quick start

Clone or download the repository and open MATLAB in the repository root. Run any package independently, for example:

```matlab
run(fullfile('Figure2', 'plot_stagewise_rso2_boxplots.m'))
```

To reproduce every executable output in this repository:

```matlab
run(fullfile('Table1',        'summarize_stagewise_physiology.m'))
run(fullfile('SuppleT1',      'analyze_physiology_wilcoxon_holm.m'))
run(fullfile('SuppleT2',      'analyze_rso2_wilcoxon_holm.m'))
run(fullfile('Figure2',       'plot_stagewise_rso2_boxplots.m'))
run(fullfile('Figure3',       'fit_rso2_sjvo2_lmm.m'))
run(fullfile('SuppleFigure1', 'analyze_bland_altman_agreement.m'))
run(fullfile('Figure4',       'analyze_four_quadrant_concordance.m'))
```

Figure 1 is a static asset and has no execution step. All executable scripts resolve inputs and outputs relative to their own locations, so they do not depend on the MATLAB current folder or an internal absolute path.

## Package convention

Each executable folder generally contains:

```text
<derived input>.csv             Frozen analysis input
<analysis_name>.m            Standalone MATLAB implementation
<output>_results.csv            Regenerated full-precision results
<output>_display.csv            Regenerated manuscript-style values
<output>_point_data.csv         Plotted coordinates, when applicable
<output>_reproduced.png         Regenerated figure, when applicable
README.md                       Package-specific methods and caveats
provenance_sha256.txt           Source and input hashes, when applicable
```

Each script writes regenerated full-precision and display-ready outputs. The committed result CSVs serve as public example outputs for manual comparison or a Git diff; internal numerical regression references are maintained separately from this public repository.

## Statistical conventions

### Table 1 and Supplementary Table 1

Table 1 uses all available observations independently at each stage. Supplementary Table 1 uses complete pairs separately for each comparison. Their sample sizes and descriptive values can therefore differ without indicating an error.

Supplementary Table 1 applies Holm–Bonferroni correction within a four-comparison family for each physiological variable: Baseline–T1, Baseline–T2, Baseline–T3, and T1–T2. Its display CSV contains the three Baseline comparisons while retaining adjusted p values from the four-comparison family.

### Figure 2 and Supplementary Table 2

The three Baseline comparisons are corrected separately within each device. Effect size is calculated as:

```text
r = |Z| / sqrt(N_nonzero)
```

The Figure 2 matrices contain nine subject rows per device, but subject 19 is entirely missing. The original figure annotation therefore reports `N = 9`, whereas comparisons use eight valid pairs and, where zero differences occur, fewer non-zero pairs.

### Figure 3

The numerical model is fitted as:

```text
rSO2 ~ SjvO2 + (1 | Subject)
```

Marginal and conditional R-squared analyses and supporting materials are not included in this public release. They are available from the corresponding author upon reasonable request.

### Supplementary Figure 1

The source calculation uses:

```text
difference = rSO2 - SjvO2
```

Bias and limits of agreement use the population standard deviation, and confidence intervals use 2,000 subject-cluster bootstrap iterations.

### Figure 4

For each subject, the code selects the observation closest to the bivariate median as a pseudo-baseline. Pseudo-baseline points are plotted but excluded from concordance. A point is retained when either coordinate exceeds the exclusion threshold:

```text
abs(delta_SjvO2) > threshold OR abs(delta_rSO2) > threshold
```

Concordance is the fraction of retained points with a strictly positive coordinate product. Confidence intervals are Wilson 95% intervals.

## Important source-alignment notes

These packages reproduce the current numerical source behavior and document, rather than silently alter, the following issues:

1. The archived Excel headers identify column 2 as rSO2 and column 3 as SjvO2. The original `LMM_AI_IN.m` plot labels describe the Figure 3 model direction in reverse. The standalone package preserves the numerical fit.
2. The original Bland–Altman plot labels the difference as `SjvO2 - rSO2`, although the calculated values are `rSO2 - SjvO2`. The point-data CSV names the calculated sign explicitly.
3. Figure 4 uses a median-nearest pseudo-baseline and an OR exclusion rule. Replacing either rule produces different concordance values.
4. MATLAB may emit a non-fatal `boxplot`/tiled-layout display warning while generating Figure 2. Numerical calculations and PNG creation are unaffected.

These points should be reconciled with the final manuscript labels before the public release is archived.

## Data and release scope

The committed CSV files contain derived, analysis-ready values required for the listed outputs. Original upstream MATLAB scripts and Excel workbooks used during extraction are not required and are not included in this flat public folder. Their filenames and SHA-256 values are retained in package documentation for provenance.

This release does **not**, by itself, demonstrate end-to-end retraining of the AI model from raw optical measurements. Any claim of training or inference reproducibility additionally requires the training/inference source, model configuration, random seeds, dependency environment, sample input/output, and model-weight access statement.

The internal workspace outside this `Github` directory contains revision correspondence, manuscript files, raw-data copies, model outputs, and debugging material. Those materials are outside the intended public release. Review all repository files for identifiers, third-party material, and data-sharing restrictions before publication.
