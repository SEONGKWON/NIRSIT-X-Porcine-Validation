# Manuscript Table 1 reproduction package

This folder contains the extracted subject-level physiology stage values and standalone MATLAB code needed to reproduce the analysis underlying manuscript Table 1.

## Files

- `physiology_stage_values.csv`: subject-level MBP, SBP, DBP, SpO2, HR, and EtCO2 values at Baseline, T1, T2, and T3.
- `summarize_stagewise_physiology.m`: stage-specific summary calculation using all available observations at each stage.
- `table1_results.csv`: full-precision output generated by the script.
- `table1_display.csv`: two-decimal median [IQR] output with N reported separately for every stage.

## Run

From the repository root:

```matlab
run(fullfile('Table1', 'summarize_stagewise_physiology.m'))
```

Alternatively, change the MATLAB current folder to `Table1/` and run `reproduce_table1`.

The extraction preserves the event-index exceptions defined by the archived internal `Pig_exception.m`. T1, T2, and T3 correspond to `after_clamping`, `before_open`, and `after_open`. The unused `before_clamping` stage is not included.

## Important behavior preserved

Table 1 summarizes each stage independently after removing missing values from that stage. It does not require a subject to have data at another stage.

- Baseline, T1, and T3 have N = 7.
- T2 has N = 8.
- Pig 11 contributes only to T2 because the other analysis windows fall outside the available Pig 11 recording range.

The calculation-derived two-decimal display differs slightly from several manually entered manuscript IQR values. This package preserves the calculation output and does not overwrite manuscript files.
