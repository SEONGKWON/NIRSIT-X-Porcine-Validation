# Supplementary Table 2 reproduction package

This folder contains the stage-level rSO2 values and standalone MATLAB code needed to reproduce Supplementary Table 2.

## Files

- `rso2_stage_values.csv`: extracted NIRSIT-X and INVOS values for Baseline, T1, T2, and T3.
- `analyze_rso2_wilcoxon_holm.m`: paired Wilcoxon tests, Holm–Bonferroni correction, manual Z calculation, and effect-size calculation.
- `supple_t2_results.csv`: full-precision output generated by the script.
- `supple_t2_display.csv`: three-decimal display table generated by the script.

## Run

From the repository root:

```matlab
run(fullfile('SuppleT2', 'analyze_rso2_wilcoxon_holm.m'))
```

## Important behavior preserved

1. Columns are `[Baseline, T1, T2, T3]`.
2. Missing values are excluded pairwise.
3. Zero paired differences are excluded from `N_nonzero`.
4. Raw p values use `signrank(x, y, 'method', 'approximate')`.
5. Z is recomputed using the no-tie normal-approximation variance and a 0.5 continuity correction.
6. Effect size is `r = abs(Z) / sqrt(N_nonzero)`.
7. Holm correction is applied separately for each device across Baseline–T1, Baseline–T2, and Baseline–T3.

Raw p and Z therefore originate from related but not identical calculation paths; the manually calculated Z does not explicitly apply a tie correction.

Subject 19 is an all-missing placeholder and contributes to no comparison. The source replaces the Pig 11 INVOS row with `[39, 26, 25, 32]` and Pig 12 INVOS T2 with 24. The differently capitalized source statement `In_plot(2,2) = 24.5` does not modify `IN_plot`, so the analyzed Pig 12 INVOS T1 value remains 22.

The exact NIRSIT-X T1/T2 Z value is 2.45049014704902, which rounds directly to 2.450 at three decimal places. Reporting 2.451 after first rounding the console value to 2.4505 is a double-rounding artifact.
