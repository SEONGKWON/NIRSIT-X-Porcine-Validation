# Figure 2 reproduction package

This folder reproduces the Figure 2 NIRSIT-X and INVOS stage-wise boxplots and their paired Wilcoxon/Holm statistics without running the original raw-data pipeline.

## Files

- `figure2_stage_values.csv`: frozen final four-stage matrix used by the source analysis.
- `plot_stagewise_rso2_boxplots.m`: standalone statistical analysis and plotting code.
- `figure2_stats.csv`: regenerated full-precision statistics.
- `figure2_display.csv`: regenerated three-decimal display statistics.
- `figure2_reproduced.png`: combined two-panel image generated by the standalone script.
- `Figure1.png`: legacy combined export from the original Figure 2 workflow.
- `Figure2.png`: legacy NIRSIT-X-only export from the original Figure 2 workflow.
- `Figure3.png`: legacy INVOS-only export from the original Figure 2 workflow.
- `provenance_sha256.txt`: extraction date and source/input hashes.

## Run

From the repository root:

```matlab
run(fullfile('Figure2', 'plot_stagewise_rso2_boxplots.m'))
```

The script writes the result CSVs and `figure2_reproduced.png`.

## Provenance

`figure2_stage_values.csv` is identical to the final stage matrix in the sibling file [`../SuppleT2/rso2_stage_values.csv`](../SuppleT2/rso2_stage_values.csv). Both were extracted from the final `AI_plot` and `IN_plot` matrices produced by the archived internal source `Pig_Result_revision.m`. The upstream script and raw-data hierarchy are not required or included in this flat public repository.

The frozen data preserve:

1. removal of the sixth row from `Box_AI` and `Box_IN`;
2. conversion of zeros to missing values;
3. selection of columns `[1,3,4,5]` for NIRSIT-X;
4. INVOS baseline selection from column 2 with column 1 fallback;
5. manual replacement of Pig 11 with `[39,26,25,32]` and Pig 12 T2 with `24`.

## Important behavior preserved

The CSV has nine subject rows per device, but subject 19 is entirely missing. The original plot annotation therefore reports `N = 9`, while each comparison has eight valid pairs. Tied pairs can reduce `N_nonzero` further. Effect size follows the source:

```text
r = abs(Z) / sqrt(N_nonzero)
```

Holm correction is applied separately for NIRSIT-X and INVOS across the three Baseline comparisons. MATLAB may emit a non-fatal `boxplot`/tiled-layout display warning; numerical calculations and PNG creation are unaffected.

## Requirements

- MATLAB R2025b or a compatible release
- Statistics and Machine Learning Toolbox
